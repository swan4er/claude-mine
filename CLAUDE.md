# claude-mine

Мод Claude Code на function hooks: воксельная песочница в полосе над строкой ввода.

Перед любой правкой прочитай `docs/agent-notes.md` — инструкцию по function hooks с измеренными
ограничениями среды и типовыми ошибками. Факты, измеренные именно для этого проекта (бюджет кадра,
мышь, хранилище, скорость лучей), — в `docs/probes.md`. Устройство игры — в `README.md`.
