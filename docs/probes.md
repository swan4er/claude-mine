# Пробы среды для claude-mine

Замеры пробным плагином 19.09.2026, Claude Code 2.1.278, tmux 140×50, полноэкранный режим. Это
факты, на которых стоят решения в коде; после обновления Claude Code — перепроверить.

| Что | Результат | Следствие в коде |
|---|---|---|
| Высота полосы | терминал 50 строк → `maxRows = 19` (формула `высота/2 − 6` подтверждена) | вид = все строки полосы минус хотбар и статус |
| Бюджет кадра, отрезок с цветом текста и фона (`▀`) | 1020 проходят, 1105 — отказ | `runs.ts` считает стоимость кадра и огрубляет |
| Бюджет кадра, отрезок с одним цветом | 1530 проходят, 1870 — отказ | где верхний и нижний пиксель равны — одноцветный `█` |
| Короткая запись цвета `#rgb` | принимается, выигрыша почти нет | не используется |
| Превышение бюджета | `a tree serializing to more than 100000 characters; the instance unmounted` — экземпляр выгружается, игра пропадает | бюджет жёсткий, с запасом; есть стресс-тест |
| Интервал кадров | 55–63 мс при 170–1020 отрезках; сборка дерева 1–6 мс | логика по `Date.now()` |
| Движение мыши без кнопки | приходит (`move`, `button` отсутствует), даже до клика | взгляд мышью |
| Правый клик | приходит: `down`, `button: 'right'` | правый клик — поставить блок |
| Клавиши после клика | `e`, `space` (именем), `tab`, цифры, `up` приходят | — |
| `$.store`, одно значение | 4 000 000 символов записаны и прочитаны за 151 мс | сохранение одной строкой |
| 5000 лучей × ≤48 шагов 3D-DDA (с `sin`/`cos` на шаг) | 23–39 мс на 215 тыс. шагов | рисовать только при изменениях |
